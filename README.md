## 🚀 Установка:  

- 📥 Скачайте <a href="https://github.com/Hacker123ter/Fruit-Test/raw/refs/heads/Fruit-Test/target/Fruit-Test-1.jar" target="_blank">Fruit-Test-1.jar</a>.  
- 📂 Переместите его в папку **plugins** вашего сервера (убедитесь, что ядро и версия совместимы с плагином).
- 🔄 Перезапустите сервер.  
- 🎉 Готово!  

## 🎮 Добавлено:  

1. Возможность выдачи "Проклятого яблока" через команду `/apple`.  
2. Съедание "Проклятого яблока" увеличивает максимальное здоровье на 20 HP.  
3. При смерти максимальное здоровье уменьшается, но не опускается ниже 20 HP.  
4. После поедания "Проклятого яблока" в 9-й слот инвентаря помещается "Фрукт Бомба".  
5. "Фрукт Бомба" нельзя выбросить, переместить или съесть.  
6. "Фрукт Бомба" не дропается при смерти и сохраняется после респавна.  

## 🏗️ Команды:  

```
/apple ### Выдает игроку "Проклятое яблоко". ## Права: fruit.apple
```
